# Last Light Keep

Every beacon in the Ashen March has gone dark but one. Build towers beside the winding roads and hold back the goblins, orcs and bosses until the Ashen King's march ends.

It's a 3D voxel tower-defense game in the Kingdom Rush style, built with Three.js. You can play it at https://claude.ai/artifact/APmUNmJzfP4saKjkqWW2kJ.

```bash
npm install
npm run dev
```
