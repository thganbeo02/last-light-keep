# Milestone 4: Hero progression

Heroes are earned in the campaign and grow with it. A hero gains experience in each played battle, levels up between battles, and spends points in a small talent tree. Watch mode stays hero-free, and testing mode (`save.dev`) opens every hero at the top level.

This is a 4.0 release: it changes how the campaign plays, and it changes the save.

## Rules

- **Recruitment.** Aldric is available from 1-1. Corwin joins after the first win on 1-3 Thornwood, where the briefing introduces him. Later heroes follow the same pattern, one per area.
- **Existing players keep Corwin.** In 3.3 and 3.4 both heroes were open to everyone. Any save with a star on 1-2 or later opens Corwin straight away, so no one loses a hero they have played.
- **Experience.** A battle gives experience for each wave survived, plus a victory bonus that grows with difficulty (casual 1×, normal 1.25×, impossible 1.5×). Replays give half. Defeats keep what was earned. Only the hero in the battle gains experience.
- **Levels.** Levels 1 to 10. Each level adds a fixed share of health and damage. Level 10 is reachable around the end of Cinderwaste without replays.
- **Talents.** Each level gives one point. Each hero has three short lanes, one per ability, plus a capstone that needs points in two lanes. A talent changes numbers (recharge, radius, duration) or adds a rule (Kindle leaves a second, smaller patch). Refunds are free between battles, as in the War Council.
- **Balance.** Level 1 heroes keep 3.4's numbers. Battles are tuned so a level-appropriate hero matters without carrying the defense: towers still decide most battles.

## Save

The save keys `voxelSiege.stars.v1` and `voxelSiege.save.v2` and the cloud path `data/users/<id>/save` don't change. Hero progress is new fields in the existing save:

```js
heroes: { aldric: { xp: 0 }, corwin: { xp: 0 } }, // level is derived from xp
heroTree: { aldric: ['...'], corwin: [] }, heroTreeT: 0, // talent picks; the newest set wins, like tree/treeT
hero: 'aldric', // the last hero picked, so the briefing remembers it (today it resets to Aldric on every load)
```

`mergeSave()` keeps the larger `xp` per hero, takes `heroTree` from the copy with the newer `heroTreeT`, and fills `hero` only when it is missing. Older saves have none of these fields and merge as level 1 with no talents.

## Hero baseline

`npm run sim -- --heroes`, 40 played battles per hero and map on normal (2026-11-27), after skills became automatic and Aldric's buff (28 damage, Hold Fast cleave, Rally's 20% boost, 12 s recovery). Each seed's no-hero battle records the build AI's purchases and all three replay them. Wins in percent, about ±8 points.

| Map | No hero | Aldric | Corwin | Aldric falls per battle |
| --- | --- | --- | --- | --- |
| Millbrook Fields | 100 | 100 | 100 | 0.1 |
| River Crossing | 63 | 65 | 65 | 3.3 |
| Thornwood | 98 | 100 | 100 | 1.7 |
| Mire’s Edge | 85 | 85 | 93 | 5.8 |
| Highland Pass | 8 | 10 | 13 | 6.9 |
| Frostmere | 38 | 40 | 48 | 9.2 |
| Ember Crater | 8 | 3 | 15 | 11.1 |

- Earlier runs let the build AI react to the hero. A hero's kills bring gold in sooner, so the AI bought different towers before the bat waves, and River Crossing swung 40 points either way. The 3.4 findings that Aldric and Kindle lowered wins there came from this, not from the heroes.
- With the same towers, a level 1 hero adds 0 to 10 points of wins and saves castle health. Towers decide battles, as this milestone intends.
- The replay leaves a hero's extra gold unspent, so these numbers measure fighting, not income.
